    Conflict resolution engine

    Data quality & conflict resolution

    Every accessibility feature on this map comes from community reports. When reports about the same venue disagree — one visitor says there's a ramp, another says there isn't — the engine tries to resolve it automatically, but only when the evidence is strong enough to trust. Everything else is left for a human reviewer rather than guessed at. Still-open cases also show a review banner on their venue detail card.

    MAST90107 · accessibility data platform

    Built on community reports,
    not assumptions.

    EnAccessMap Melbourne is a student project that turns raw accessibility reports into a map you can actually plan a trip around: step-free entry, accessible bathrooms, seating and parking, plus where the nearest accessible public toilet is.

    Inspired by EnAccess Maps

    This project's data schema and filter-by-accessibility-criteria approach follow the model pioneered by EnAccess Maps, a Melbourne not-for-profit founded by Sabrina Leung. Their assessors and volunteer reviewers vet venues on step-free entry, bathrooms, seating and parking — the same four criteria this map filters on.

    How confidence is calculated

    Each feature — ramp, bathroom, seating, parking — is scored from the share of matching reports. Five people confirming a ramp exists scores higher confidence than one. The five-dot meter on every venue card is a direct read of that evidence count, not a guess.

    Four map layers

    Venues — cafes, restaurants, culture and shops with reported accessibility features. Public toilets — Victorian council toilet data, accessible facilities highlighted. Tactile paving (TGSI) — tactile ground surface indicator points for low-vision and blind wayfinding. Flagged for review — venues with disagreeing reports.

    Built with

    Leaflet.js + OpenStreetMap tiles, a Python export script that turns database/accessibility.sqlite into static JSON, and vanilla HTML/CSS/JS — no build step, hosted for free on GitHub Pages.

    Data sources

    This is an MVP built for a university unit. Accessibility information reflects community reports, not a guarantee — always call ahead if a visit depends on it.
